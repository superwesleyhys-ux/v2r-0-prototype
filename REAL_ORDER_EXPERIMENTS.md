# Real Order Experiments

The next milestone is not more UI. It is proving that a natural-language Reality Ticket can become a low-risk physical object that is sourced, printed, checked, delivered, and learned from.

Run these as real or half-real orders before expanding categories.

## Shared Record Fields

For every experiment, record:

- Ticket ID
- User intent
- Template ID
- Risk class
- Required measurements
- Selected plan
- Quoted landed cost
- Actual material grams
- Actual print time
- Actual labor minutes
- Standard parts used
- Packaging cost
- Shipping or pickup method
- Failed print count
- QC result
- User feedback
- Rework or refund action
- Template updates needed
- Price rule updates needed

## Order 1: Desk-Edge Headset Hook

Goal:

Validate the clamp-style template, BOM, QC checklist, and quote engine.

Fulfillment path:

- 3D print main body
- Use inventory M4 screw and nut
- Use inventory or purchased rubber pads
- Run clamp and cable-slot QC

Record:

- Desk thickness
- Headset weight
- Print orientation
- Material grams
- Print time
- Actual material cost
- Failed print count
- Installation stability
- User satisfaction

Pass condition:

The hook clamps to the provided desk thickness, holds one headset without obvious sliding, and the user can install it within five minutes.

## Order 2: Cable Management Clip

Goal:

Validate low-cost small parts, multi-piece printing, and simple packaging.

Fulfillment path:

- Print three to five clips
- Use adhesive pads if needed
- Package as a small kit

Record:

- Cable count
- Cable diameter range
- Mount surface
- Batch size per print
- Adhesive reliability
- Whether size variants are needed
- Repeat-purchase interest

Pass condition:

The clips hold the target cables in the intended position for at least one day without obvious detachment.

## Order 3: Drawer Divider

Goal:

Validate user measurement accuracy and custom-fit structure.

Fulfillment path:

- User provides drawer dimensions
- System creates divider spec
- Print modular divider walls or connector tabs
- Run fit and edge QC

Record:

- Drawer inner dimensions
- Measurement method
- Actual fit error
- Whether photo-assisted measurement was needed
- Material grams
- Print time
- Any warping or fit issue

Pass condition:

The divider fits inside the drawer without forcing, separates the intended items, and does not require tools to install.
